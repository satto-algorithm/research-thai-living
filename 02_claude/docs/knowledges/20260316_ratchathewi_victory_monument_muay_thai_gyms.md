### 1. Tded99 Muay Thai Gym（テデット99 ムエタイジム）

**基本情報**
- **設立**: 1997年頃
- **スタイル**: ムエマット（パワー系）+ ムエフィムー（テクニカル系）のブレンド
- **最寄りBTS駅**: サパーンクワーイ（Saphan Khwai / N7）徒歩約15分（1.2km）
- **住所**: 16 Inthamara 9 Alley, Samsen Nai, Phaya Thai, Bangkok 10400（9階建てビルの屋上）
- **営業時間**: 火〜日（月曜定休と推測）

**スケジュール**
- 朝練: 7:00〜8:30（ランニング、パッドワーク、S&C、ウェイト＆コア、ストレッチ）
- 午後練: 15:00〜18:00（4kmラン → 10分縄跳び → シャドー → パッド5R → バッグ → クリンチorスパー30分 → ウェイト＆コア）

**料金体系**
| 種類 | 料金 |
|------|------|
| グループクラス（1回） | 1,600 THB |
| プライベートセッション（1回） | 1,800 THB |
| Contender Pack（月額グループパス） | 4,900 THB |
| Champion Program（月額無制限 + プライベート3回） | 9,900 THB |

**特徴・レビュー**
- ルンピニー・ラジャダムナン両スタジアムのファイターを多数輩出
- 屋上ロケーションで開放感あり、眺望も良い
- 本格的なファイターキャンプの雰囲気。観光客向けではなくガチ志向
- グローブ貸出あり

**公式情報**
- Web: https://muaythaibkk.com/gym/tded99
- NOW Muay Thai: https://www.nowmuaythai.com/gym/tded99-muaythai-gym
- Instagram: @t_ded99

### 目的別おすすめ（このエリア限定）

**本格ムエタイ・ファイター志向**
1. **Tded99** - ルンピニー/ラジャダムナンファイター輩出。午後の4時間セッションは圧巻
2. **FA Group** - ムエカオ（膝+クリンチ）を極めたいなら最高峰
3. **Banchamek** - ブアカーオの名の下、少人数制で高品質な指導

**コスパ重視**
1. **FITFAC Ari店** - 月額3,500THBは最安級。チェーン展開で安心感
2. **Tiger Eye** - 月額4,500THB、ドロップイン500THB。複数格闘技OK
3. **Rithirit** - 月額5,500THB、ドロップイン500THB。歴史あるジム

**初心者・女性**
1. **Tiger Eye** - 女性専用クラスあり。パーマカルチャーガーデンの開放的な環境
2. **FITFAC** - フィットネス志向。初心者に優しい
3. **Banchamek** - 少人数制（最大7名）でパーソナライズされた指導

**DTV（Destination Thailand Visa）対応**
- Tiger Eye MMA（書類サポートあり）
- FITFAC（99%承認率を謳う）

### 注意事項
- N1 ラチャテウィー、N3 戦勝記念塔の駅直近には本格的なムエタイジムが少ない
- このエリアに住む場合、N5 アーリー〜N7 サパーンクワーイ方面（BTS 2〜4駅、5〜10分）のジムに通うのが現実的
- ラジャダムナンスタジアム（観戦用）へは、ラチャテウィー or 戦勝記念塔からタクシー100THB以内でアクセス可能
